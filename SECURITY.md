# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities to **security@scalables.com**. Do not open a public GitHub issue for security reports.

You can encrypt your report with our PGP key at https://scalables.com/.well-known/pgp-key.txt (fingerprint `E431 2833 B2BF 7E97 8399 0B98 3DD1 E4F1 239F 2DA4`).

Please include the Daisy Controller Software version (Settings → Versions), your operating system, a description of the issue, steps to reproduce, and its impact.

We acknowledge reports within 2 business days.

## Supported versions

Security fixes are released for the current Daisy Controller Software release. Please update to the latest release before reporting.
